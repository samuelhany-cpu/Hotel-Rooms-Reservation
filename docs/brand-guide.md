# BookingCW — Portfolio Demo Design System

## Positioning

BookingCW is a fictional boutique-hotel booking concept, not an operating accommodation business. All room descriptions, amenities, images, and prices are sample content. The search UI is illustrative until Milestone 3. No actual reservation or charge is processed.

## Brand system

- Brand: **BookingCW**
- Voice: calm, welcoming, informative. No invented ratings, guest counts, addresses, or performance promises.
- Colors: deep ink `#21323C`, warm paper `#F8F6F1`, ivory `#FFFDF9`, bronze `#8B663E`, secondary text `#59656A`.
- Typography: Poppins for interface; Georgia serif for editorial headings.
- Spacing: 8px rhythm, content width up to 1180px.
- Controls: reusable buttons, text links, room cards, booking fields, notices, and consistent focus states.
- Motion: subtle hover transitions, respecting reduced motion.
- Images: temporary reuse of existing repository images, pending license/ownership verification. All photos are illustrative.

## Verification

Manually test 360×800, 390×844, 768×1024, 1024×768 and 1440×900, keyboard and screen reader, 200% zoom, and reduced motion. Browser screenshots and Lighthouse require accessible preview/runtime.

## Boundaries

No new backend, payment, accounts, or booking backend. A fully working deterministic reservation demo belongs to Milestone 3.
